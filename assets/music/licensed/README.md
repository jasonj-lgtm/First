# Licensed music beds

Drop royalty-free / licensed tracks here (`.mp3`, `.m4a`, `.wav`, `.aac`).
`reveal_builder` picks one at random when no `--music` is passed.

Rules (upgrade spec, Phase 6):
- Never reuse audio lifted from past reels or other people's content.
- Every file here must be either (a) licensed/royalty-free with the license
  noted below, or (b) generated originals (`t1p-bed-*.wav`, made by
  `tools/make_music_bed.py` — original synthesis, no licensing required).
